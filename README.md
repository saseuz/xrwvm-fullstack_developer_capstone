# xrwvm-fullstack_developer_capstone

## Project Name: Full Stack Application Development Capstone Project (National Car Dealership Review Application)

- **Repository Name:** xrwvm-fullstack_developer_capstone
- **Project Name:** Car Dealership Review Full-Stack Application

### Project Overview
This repository contains the Full Stack Software Developer Capstone Project. It is a national car dealership management and review web application built using:
- **Frontend:** React, HTML, CSS, Bootstrap
- **Backend:** Django, Python, Node.js, Express
- **Database:** SQLite (Car Makes & Models), MongoDB (Dealerships & Reviews)
- **Microservices:** IBM Code Engine Sentiment Analyzer
- **CI/CD & Deployment:** GitHub Actions (Flake8 & JSHint), Docker, IBM Cloud Container Registry, and Kubernetes.
